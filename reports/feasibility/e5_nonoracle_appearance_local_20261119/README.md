# E5：非 GT 外观选择器与几何对照的配平局部分支

**运行范围：** DanceTrack train 的固定 24 段 fit，CPU-only，`CUDA_VISIBLE_DEVICES=''`；物理 GPU 0–7 均未使用。协议为 `manifests/protocols/e5_nonoracle_appearance_local_20261119.yaml`，SHA256 `62b3b98f875cad1d3610bdc28f91e359edfe3b53ffc3585ec82e87ec5c8a3942`。这是五帧局部分支诊断，不是完整序列闭环方法或官方 TrackEval。

## 问题与固定方法

E4 在 GT 选出的已错过正检测事件上显示一次正确配对有短程收益，但无法在线选择配对。E5 不用 GT 建候选或选动作：从原 CV 的 C 输出寻找上次输出后 2–30 帧、首次有至少两个空间接近的高分检测的轨迹缺口；每段以固定 SHA256 排序最多选 30 个事件。轨迹须曾成熟且在首轮关联时存活。当前已与目标配对的检测从待选项移除。外观规则取旧 C 框与当前检测框内 70% 区域的 12×4×4 HSV 直方图相似度，并以固定的外观分数和 margin 门槛筛选；几何规则在外观通过门槛的**同一事件**上，按预测框/旧 C 框 IoU 与检测分数选择。两者各在相同预帧状态上强制一个一对一首轮配对，后四帧均恢复原 CV+E。GT 只在两个分支及原始轨迹已保存后，用于判断历史 C 身份与五帧正确输出。详情见协议和[实现脚本](../../../scripts/run_e5_nonoracle_appearance_local.py)。

## 拟合结果与预写判定

24 段共有 **1,515** 个在线可观察的首次缺口候选；固定哈希最多 30/段后选 **664** 个。87 个未过外观门槛，1 个目标未成熟或未存活，余下 **576** 个事件两方法均执行动作。选择检测不同的只有 **47** 个事件。576 个中 529 个能用上次 C 输出锚定目标 GT，233 个当帧有与目标 GT 匹配的高分检测；选择正确正检测为几何 102、外观 99。未出现正检测的事件不能记作选错正检测。

## 来源、审计与限制

- 原始产物：`/media/imc/data/mot-data/runs/e5_nonoracle_appearance_local_fit_20261119/`。含每段原始两支五帧输出、逐事件评分 JSONL、分段哈希、代码/依赖来源。`summary.json` SHA256 `7ec8d4dde1b2d041f100bb150abf99289386553b34093e2c5074e8762a3ebdbb`；墙钟约 1,420 秒，CPU 核时约 0.395 小时，峰值 RSS 481,312 KiB。
- [独立完整性审计](../../../docs/audits/e5_nonoracle_appearance_local_20261119/EXPERIMENT_AUDIT.md)为同系列 provisional `WARN`：全部 576 个原始事件由另一套 IoU/匈牙利代码独立重算，无数值差异；来源、配平及父回放通过；WARN 是拟合集、局部分支和重叠窗口的范围限制。
- 外观置信度决定两方法共同的动作事件，既不是全候选评测，也不能说明所有外观表征。简单几何对照本身也造成大量损伤；这组触发条件和强制配对策略不能直接用于在线方法。E5 不提供完整视频 HOTA/AssA/IDF1 或可部署改进。按停止规则，当前外观选择器到此为止；进一步研究若要继续，需要新问题与新协议，而非在同一 fit 或留出集反复调参。
