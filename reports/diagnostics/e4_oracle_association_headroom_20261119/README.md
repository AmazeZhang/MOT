# E4：正确再关联的一次 GT 特权短程反事实

**范围：** DanceTrack train 内固定 24 段 fit；不用 8 段 train 留出、motion-dev 或官方 val。协议为 `manifests/protocols/e4_oracle_association_headroom_20261119_retry3.yaml`，SHA256 `1e286bee37b6fc0aec90b865f23df8aecab56f568be1218774adff2647208068`。CPU-only，`CUDA_VISIBLE_DEVICES=''`，物理 GPU 无。本实验是 **GT 特权、独立五帧分支的 headroom 诊断**，不是数学最优上界、可部署方法或官方完整序列评测。

## 为什么做这一项

E0 在 831 个固定开发事件中除输出抑制外，还记录 242 个“原目标未由注册正检测更新”的首断点。E1–E3 的输出规则不改变内部配对。E0–E3 的独立同系列 `result-to-claim` 审阅据此否定“输出门控已修复内部身份”的宽主张；见 `docs/e0_e3_claim_gate_20261119.md`。E4 只回答：**如果在一次真实重现时把正确检测强行配给原轨迹，未来四帧是否留下足够的可见身份收益？**

候选从 E3 的 C 原输出与真实 DanceTrack GT、固定高分检测建立：同一 GT 上次与 C 输出的身份锚点距当前 2–30 帧，当前有 GT IoU≥0.5 的高分检测，且未来至少四帧仍在视频内；每个缺口只取第一次符合的重现。每段按固定 SHA256 排序最多取 50 个候选，之后才检查轨迹曾成熟、首轮仍存活、原 CV 回放未由该正检测最终更新。每个有效事件都从**同一预帧 CV 状态和历史**复制两支：正常关联，或移除冲突配对后强制正确的一对一配对。两支只在这一帧不同；其后四帧均按原 CV + E（成熟轨迹分数≥0.8 再输出）规则运行。GT 用于选择事件和 oracle 配对，明确不可在线获取。

## 结果与预写门槛

24 段共有 1,903 个候选缺口；固定哈希最多 50/段后选中 1,073 个。选中者中 617 个原回放已经由正检测正确更新，2 个未达到成熟定义；余下 **454 个有效错配事件**构成主分母。所有 24 段父回放的 C/E 帧、ID 与 E3 参考一致，框误差≤1e-4；正常五帧分支也与 E3 E 参考一致。以下“正确帧”指 GT 在 IoU≥0.5 匈牙利匹配下取得历史锚定的原 ID；不同事件窗口可以重叠，不是独立视频重复。

## 来源、失败记录与解释边界

- 成功运行：`/media/imc/data/mot-data/runs/e4_oracle_association_headroom_20261119_retry3/`，`summary.json` SHA256 `628e979e86a0478f15f69df2a040192986d84fc0044b83b8e801bc71e772f7dd`；含 24 份逐事件 JSONL、每段输入及事件行哈希、代码/依赖来源。墙钟约 1,528 秒、CPU 核时约 0.424 小时、峰值 RSS 463,212 KiB。
- 先前三次执行在工程验收时失败，分别因 OC-SORT 原地改变共享输入数组、全局轨迹出生 ID 计数器在分支间串扰、以及评价锚点误用 E 输出。失败目录分别为同名前缀 `.failed`、`_retry1.failed`、`_retry2.failed`，均保存错误与当时脚本；它们没有完整结果，未纳入分母。`retry3` 修正代码与新协议另存，不覆盖旧产物。
- 主分母是经 GT 和原输出定义的候选再经正常回放排除后得到，**受条件选择约束**：不能把 454/1,903 当成自然错误率，也不能把每事件 +3.141 帧乘到整个数据集估算 HOTA。454 个五帧窗口有 2,270 次帧暴露，对应 1,750 个不同视频帧，387 个视频帧在多个窗口出现；不能当成独立的 2,270 帧或 454 个视频。统计单位是视频；本轮没有置信区间、官方 HOTA/AssA 或完整序列 oracle 轨迹。
- 新鲜同系列 `experiment-audit` 为 provisional `WARN`，见 `docs/audits/e4_oracle_association_headroom_20261119/EXPERIMENT_AUDIT.md`：候选、抽样、原始行、哈希、正常回放及门槛算术复核通过；独立重放一个事件吻合。全部 oracle 分支轨迹没有逐帧归档，若要逐项独立复算所有 oracle 得分需要重新运行；这是审计性限制。
- 结论仅为：在这组已选中且正常回放未正确更新的成熟轨迹重现事件上，正确配对有**构造性短程改善空间**。它不证明已有可观测特征能找出正确配对，也不证明外观、运动生成器或任何学习方法会取得同等收益。下一步若继续，应先固定一个不读 GT 的信息源，在相同候选和一对一预算下与 CV+E、简单 IoU/分数规则对照；没有非特权选择效果前，不训练 FM/MDN 或跑官方 val。
