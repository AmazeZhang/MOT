## 1. 本轮结论

建议结束“继续给 OC-SORT 添加一条局部规则”的主线，把下一轮有限预算用于**有学习能力的视觉关联及其闭环可靠性**。先建立深度外观对照和 MOTIP 官方模型验收，再决定研究哪一种机制。不要立刻从头训练大型模型，也不要把“使用 Transformer／Mamba／Flow Matching”当成选题成立。

目前只有一条值得优先验证的研究假设、一条低成本备用假设和一条暂缓方向；没有三条已经成熟的新方法。尤其是“用真实错误训练”“置信度控制记忆写入”“不确定时调用分割”“增加拒绝选项”，本轮都发现了直接或紧邻先例。

最有价值的转变是：从“怎样把已有运动预测器改好”，转向“**关联错误发生后，当前与历史的视觉证据是否足以识别并阻止错误持续传播**”。这仍是问题定义，不是已经证明的机制。

文献条目、检索限制和代码核查见 [allinone.md](allinone.md)；实验来源见 [整体复盘](../../docs/research_status_review_20261120.md)。

## 2. 实验对选题施加的约束

| 已有观察 | 支持的行动 | 不支持的外推 |
|---|---|---|
| P1 一步预测改善，但自然闭环输给 CV | 后续优先测完整序列和真实推理历史 | 不能断言误差完全来自历史污染，也不能否定所有运动学习 |
| R1 13 维线性效用选择器输给简单 IoU 对照 | 学习方法必须比较强简单对照，并说明新增信息 | 不能断言关联学习无效 |
| E2 的 E−C 在 dev/fit 约 +0.300/+0.221 HOTA，AssA 增益较小且有 IDSW/FP 代价 | 保留 CV、CV+E，固定输出政策 | 不能把输出补回包装成身份建模创新 |
| E4 454 个 GT 条件化事件全锚点净增 1,643 帧 | 身份关联存在条件化短程收益空间 | GT 触发和答案不可部署；不能换算为整体 HOTA |
| E5 576 次强制动作中 529 次两规则同选；几何/HSV 均大量伤害其他身份 | 新实验必须允许维持原配对，评价整个冲突集合 | HSV 负结果不等于深度视觉或多帧证据无用 |
| E5 的 47 次分歧中仅 5 次正检测位于替代池 | 先检查候选动作是否覆盖正确答案 | 在这个受限池里换更强分类器不能直接回答视觉是否有信息 |

这些结果说明当前触发、动作空间和输入表征都有限制。它们还没有证明哪一项是主因。新的实验应分离“没有信息”“信息有但解码失败”“动作会伤害别人”“只改善局部不改善整段”四种解释。

## 3. 文献改变了哪些判断

**可学习关联已有较成熟入口。** [MOTIP（CVPR 2025）](https://openaccess.thecvf.com/content/CVPR2025/html/Gao_Multiple_Object_Tracking_as_ID_Prediction_CVPR_2025_paper.html)把当前检测的身份预测作为学习任务；[LA-MOTR（ICCV 2025）](https://openaccess.thecvf.com/content/ICCV2025/html/Wang_LA-MOTR_End-to-End_Multi-Object_Tracking_by_Learnable_Association_ICCV_2025_paper.html)也直接学习关联。这让我们的资源可以投入真正的表征与关联学习，而非一直局限于少量人工特征。

**训练与推理历史不一致不是空白。** MOTIP 已有随机轨迹遮挡和身份交换增强；[MOTIP2（作者标注 BMVC 2026 accepted）](https://arxiv.org/abs/2610.10391)进一步采用空间相关的身份交换、空间损失和位置表征。更早的 [CVPR 2019 exposure-bias 工作](https://openaccess.thecvf.com/content_CVPR_2019/papers/Maksai_Eliminating_Exposure_Bias_and_Metric_Mismatch_in_Multiple_Object_Tracking_CVPR_2019_paper.pdf)与 [UAI 2022 event-aware learning](https://proceedings.mlr.press/v180/lee22a.html)已涉及自身错误或模拟跟踪状态。因此“真实 rollout 比随机噪声更好”必须与这些思想正面对照，不能直接作为首次贡献。

**保守调用额外证据已有很近的工作。** [BUSCA（ECCV 2024）](https://arxiv.org/abs/2407.10151)结合视觉与时空候选处理未匹配轨迹；[SAM-Deep-EIoU（2026 预印本）](https://arxiv.org/abs/2606.13033)在选择性的歧义场景引入掩码传播。仅把 SAM 接到不确定事件上，重合风险高；其不同实验设置是否严格在线需要逐项核查，不能混用带全局处理的数字。

**可靠记忆同样拥挤。** [MeMOTR（ICCV 2023）](https://arxiv.org/abs/2307.15700)已有长时记忆；[HMP（Electronics 2026）](https://www.mdpi.com/2079-9292/15/11/2357)已有可靠性写入、多原型和保守恢复；[LiAM-SAM（2026 预印本）](https://arxiv.org/abs/2609.28078)涉及生命周期感知记忆。增加 EMA、双记忆或置信度门本身不足以形成新的主张。

## 4. 候选 A：针对竞争身份污染的视觉关联训练（优先验证）

### 问题、假设与可能的差异

当邻近对象发生错配，历史中的身份和视觉内容可能持续错位。**待检验假设：** 相较于独立随机交换和空间交换，在训练中保留真实竞争关系、错误持续时长以及对其他轨迹的影响，能改善自然闭环关联，而不损伤本来正确的轨迹。

候选实现是利用冻结跟踪器在训练序列上产生的历史，构建包含当前对象、竞争身份、历史视觉特征和位置的训练片段，训练关联解码器。GT 只产生训练标签；推理必须仅访问当前及过去帧。需要保留原本正确、错误、当前无可匹配对象的样本，不能只训练 GT 筛出的错误事件。

**与近邻的待证差异：** 不只是交换位置更合理，而是建模竞争集合中的持续错误及其全体后果。必须证明这种结构超越“同样长度、同样噪声量的交换增强”。这个差异目前没有经过完整新颖性审查，也没有被本项目数据证实。

### 最小验证

先在一个冻结检测/特征版本内建立以下对照，所有条件使用相同解码器、训练步数和数据预算：

1. 原 MOTIP 训练增强，作为强基线；干净历史仅作机制参照。
2. 空间相关身份交换增强。若无法复现 MOTIP2 全系统，应明确只是其增强思想的适配对照，不称为 MOTIP2 复现。
3. 相同错误比例、持续时长的非结构化污染对照。
4. 真实 rollout 历史，保留竞争集合结构；另做打乱竞争关系的消融。

第一轮不同时增加新 backbone、外观损失、记忆门和解码算法。冻结特征方案需要新增训练接口，并非官方脚本原生承诺。缓存特征与在线提取必须抽样数值对齐。

使用训练内按视频分折生成 rollout；生成轨迹的模型不能在对应验证折调参。最终评估必须是模型自己的历史，不能用 GT 对齐历史替代自然推理。官方 DanceTrack 训练权重可能已经见过我们内部 24/8 划分：它们可用于工程验收，但内部划分上的性能不能称为独立泛化；严谨训练对照需重新限定预训练数据来源，或在另一未用于拟合的数据范围确认。

### 什么会否定它

- 空间交换或配平的普通污染已经达到相同效果：不再主张真实竞争结构有效。
- 只在人工污染或一步指标上提升，自然完整序列无收益：停止当前方法主张。
- 收益来自更多训练样本、检测器变化或评测泄漏：重做对照，不算方法证据。
- 新基线上的自然错误不表现出所假设的持续污染：优先否定机制，不继续添加复杂模块。

毕业设计潜力在于“问题诊断—训练分布建模—受控方法—自然闭环验证”的完整链条。只有各环节成立才成为方法贡献；单纯复现 MOTIP 是工程积累。

## 5. 候选 B：允许保持原结果的冲突集合决策（低成本备用）

**假设：** 深度视觉证据对一部分竞争事件有增量信息，但必须一起考虑被换出的身份，才能把信息转化为净收益。E5 提供了动作冲突线索；它没有证明这个新假设。

复用 R1 的合法对称差连通分量和克隆回放工具。候选必须包括 A0（完整保留原分配）和 A1（完整合法替代分配）；无检测/未匹配状态应有明确语义，不能强制抢走其他人的检测。候选生成不能访问 GT，原配对的正确检测不能像 E5 那样被排除。

先比较固定几何与固定深度特征，再比较单帧、简单 EMA、多帧轻量注意力。每轮只改变一种因素。允许学习整个分量的相对效用，但训练标签同时计入目标与其他身份；由 GT 未来窗口生成标签属于离线监督，推理不得读取未来。候选动作的 GT 最佳选择仅作诊断参考，不作为在线触发。

对照至少包括不动作、固定深度特征的标准一对一匹配、置信度/margin 规则，以及配平动作数量的简单策略。冻结一个预算或风险政策后测整段视频，不能在测试集按 GT 挑动作预算。在线精度改善和净正确帧必须同时报告干预覆盖率、损伤率与运行代价。

最近先例包括 [DeconfuseTrack](https://openaccess.thecvf.com/content/CVPR2024/papers/Huang_DeconfuseTrack_Dealing_with_Confusion_for_Multi-Object_Tracking_CVPR_2024_paper.pdf)、[TrackTrack](https://openaccess.thecvf.com/content/CVPR2025/html/Shim_Focusing_on_Tracks_for_Online_Multi-Object_Tracking_CVPR_2025_paper.html)、BUSCA，以及 R1 自己已有的分量动作设计。因此“加匈牙利／加不动作／用图网络”不是新意。候选差异只能是经验证的集合收益建模或新的可观测证据。

**停止条件：** 强深度外观对照已吸收收益；选择器只会全部拒绝；局部净收益不能转为完整序列收益；或找不到超越既有分量设计的区别。该方案成本低于换整套跟踪器，但仍可能回到旧规则链，故只保留一次有界试验。

## 6. 候选 C：可靠记忆写入与独立视觉验证（暂缓）

假设是错误的身份更新污染记忆，后续误配因此持续。候选组件可包括暂缓写入、稳定参考记忆、掩码/局部前景特征验证；但 HMP、LiAM-SAM、SAM-Deep-EIoU 已覆盖很多相近设计。

先做诊断：在相同关联动作和检测流下，仅改变是否写入视觉记忆，观察自然错配后的延续。必须分别计入冻结记忆造成的适应性损失；不能把“不写入 GT 已知错误”当可部署方案。若只是一般置信度门能改善，就优先把它作为强对照，暂不另造复杂结构。

**暂缓原因：** 当前 E5 基本没有深度视觉记忆可供污染，直接从其结果推导记忆方法跳跃过大；先要有一个真实使用视觉记忆的基线。SAM 等新增组件又会带来显存、速度与归因负担。除非 A/B 的结果明确指向这一机制，否则不启动。

## 7. Flow Matching 的位置

当前不恢复 FM 训练主线。已有负结果没有证明概率生成不可能有效，但我们还缺少“多模态预测比强视觉/几何对照增加有效信息”的证据。即使 FM 能拟合多峰分布，也仍需解决候选覆盖、身份竞争与安全决策。

重新开启条件应是：在自然观测历史上，简单高斯/MDN 或多候选模型已展示稳定的分布信息增益，并且该增益在固定关联策略下改善闭环；再问 FM 是否提供额外收益。这个顺序避免用复杂生成器承担尚未成立的任务需求。普通 network flow 与生成式 Flow Matching 不是同一种方法，检索不能混为一谈。

## 8. 推荐的执行次序与资源预算

以下为规划预算，不是实测训练时长或已经冻结的运行协议。只开展一条主线，另一条作备用。

| 阶段 | 做什么 | 交付物与退出条件 |
|---|---|---|
| S0：1–2 个工作日 | 审核官方代码/权重与训练数据；隔离环境；一段视频验收 | 权重哈希、配置、数据来源、输出格式、显存/耗时；拿不到可用权重或依赖难以稳定就停止迁移排障 |
| S1：2–3 个工作日 | 固定现有检测做深度外观对照；验收 MOTIP 官方推理 | 同检测内比较 CV+E 与深度外观；MOTIP 作为单独系统，不能拿其分数直接减旧 dev 分数归因 |
| S2：2–3 个工作日 | 在新基线上检查自然身份错误、污染持续与可分辨性 | 先回答 A 的机制是否存在；若不存在，不训练 A。必要时转 B 的一次有界信息验证 |
| S3：约一周开发窗口 | A 的配平训练对照，或 B 的轻量选择器 | 最多两次有记录的开发修订；有一致自然闭环信号才扩到 3 seeds/更多序列；不是一次失败就否定全领域 |
| S4：信号成立后 | 冻结方法与确认方案，再扩展数据集 | 完整序列 HOTA/AssA/IDF1、损伤与速度、消融、跨数据集验证；仍不能承诺发表 |

推荐 S0/S1 的入口：

- [Deep OC-SORT 官方代码](https://github.com/GerardMaggiolino/Deep-OC-SORT)：作为深度外观强对照。README 默认例子有 `--post` 和插值结果，严格在线比较须关闭，并固定相机运动补偿、检测和输出政策。重用其特征提取器不等于完整复现其论文结果。
- [MOTIP 官方代码](https://github.com/MCG-NJU/MOTIP)：模型、配置和权重链接可见；官方训练指南提示训练波动，不能把一次小幅增益当成立。优先官方推理验收，再考虑改训练接口。
- BUSCA 的官方 README 有推理适配和权重，但训练章节仍是 Coming soon；LA-MOTR 的论文代码地址本轮通过连接器访问返回 404。两者目前不适合作为首选训练底座。MOTIP2 的方法与训练说明已查阅，本轮未核实可用官方代码/权重，先当强先例。

硬件按本项目实际可用范围规划：8 卡机器中物理 GPU0 保留桌面，项目最多使用 1–7，启动前检查占用。第一轮优先单张空闲 4090；后续可用 4 张卡保持方便的全局 batch，剩余卡跑独立 seeds，无需强行 7 卡或照抄官方 8 进程命令。单进程 `CUDA_VISIBLE_DEVICES=1` 时进程内 `cuda:0` 是物理 GPU1，必须记入元数据。

3060 12GB 仅先计划环境验收、小分辨率推理和轻量头；完整配置能否容纳要实测。MOTIP 官方提供 checkpoint 节省显存设置，但不是对本机配置的保证。不能把多卡显存视作单卡连续大显存。

新环境与现有 OC-SORT 环境分离。MOTIP 当前安装文档推荐 Python 3.12、PyTorch 2.4 和 CUDA 12.1 组合，涉及 Deformable Attention 编译；实际安装先核对驱动与编译器。第三方 checkout、权重、特征缓存与输出放 `/media/imc/data/mot-data`；服务器主仓库保留 `/home/imc/yzy/MOT`，机器记录在忽略的 `local/`。本轮未安装或下载权重。

## 9. 评价与决策规则

1. **信息增益先于复杂模型。** 单帧深度特征、EMA、多帧轻量模型逐级比较；同等数据/计算预算。无信息的候选池不能靠训练弥补。
2. **完整序列为主要证据。** 局部正确帧用于诊断；完整序列报告 HOTA、AssA、IDF1、DetA、IDSW、FP/FN、速度和显存。固定输出政策，避免再次把补输出误认为身份收益。
3. **单位是视频与训练重复。** 重叠事件窗口不作为独立样本。可按视频做配对汇总/重采样，但 HOTA 要从相应序列统计正确重算，不能简单平均已有 HOTA。少视频的区间不宜夸大；随机种子波动单列。
4. **旧划分均诚实标注。** motion-dev 与 train 24/8 都已有历史用途，不能重新包装成从未查看的测试集。新方法的确认可使用冻结后的官方 val 和另一数据集，但需披露 val 已有基线评估史；正式 test 提交另行安排。
5. **先导门是投入决策。** 本文不事后发明统一的“+0.1 就成功”门；S0/S1 的波动与覆盖率用于在方法训练前确定最小有用效果和计算预算。确认集不得用于再定门槛。全拒绝得到零损伤不算有效方法。
