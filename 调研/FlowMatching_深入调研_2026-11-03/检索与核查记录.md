# 检索与核查记录

日期：2026-11-03。任务是毕业设计初期可行性调研，不是论文正式同行评审，也未执行真实训练。原始范围是两个调研文档中的 Flow Matching 方向。

## 七步工作记录

1. **分解主张。** 见 `step1.md`：在线固定检测 MOT；历史/缺失条件 FM；样本关联；身份监督回传运动生成器；可选动态计算。
2. **多源检索与去重。** 六源 API 的三组查询、36 条返回及错误保存在 JSON/日志中；按规范化题名组织成 30 组。另对已知方法、引用链及新颖性主张做定向网络检索。2022–2026 的初始范围之外，追溯补入 TrajE 2021。不能将这个检索量解读为完整覆盖整个领域。
3. **摘要初筛。** 全部 API 题名组在 `allinone.md`，包括摘要、作者、来源、DOI/URL、保留或排除理由。摘要缺失的记录均保留待核实；与动画、配体生成、多模态单目标跟踪等不同任务的条目不用于核心证据。预印本和期刊元数据未混同为同等级证据。
4. **选最近工作。** 正文重点选择 DiffMOT、DiffuTrack、MoFlow、TrajFlow、GenPT、OA-SORT、DOA-SORT 七篇；通过额外检索加入 TrajE、MOTIP2、DMMTracker、Constraint-Aware FM，以检验“多假设”“空间 ID 监督”“判别运动”和“下游决策对齐”的已有先例。
5. **正文与实现核查。** 七篇 PDF 已保存与抽取；阅读方法、相关实验和局限，不声称逐项复现。MOTIP2 与 Constraint-Aware FM 读取 arXiv HTML 方法。TrajE 读取 arXiv 摘要和研讨会论文的方法概述；DMMTracker 只读取作者机构页面摘要。DiffMOT 与 DiffuTrack 读取关键源码；与官方 TrackEval 对照。没有运行作者的训练程序。
6. **四轴对比。** 主报告 §3 对照问题、机制、洞察、领域。大框架重合高，具体身份监督梯度路径仍有差别；不能将“没有检出完全同名方案”当作创新证明。
7. **形成差异与可证伪方案。** 主报告 §5–7 给出小模型、实际采样反传、未匹配处理、MDN/直接关联基线、诊断实验及继续/调整条件。结论为有条件继续 pilot，不锁定论文创新主张。

## 核心证据定位

| 证据 | 阅读定位 | 支持的判断 | 不支持的判断 |
|---|---|---|---|
| DiffMOT | §3.2.4、§4；`models/diffusion.py` 采样函数 | 已有单步生成运动预测；公开返回有 detach | FM 必然更快；任意复用 sampler 都能关联反传 |
| MoFlow | 方法、蒸馏与评价指标 | K 组预测、单步蒸馏；轨迹预测任务 | best-of-K 改善即 ID 分配改善 |
| TrajFlow | §III-B、§IV；PL 排序和 self-conditioning | 多候选排序及训练输入捷径已有讨论 | 首次用 FM 排序未来轨迹 |
| GenPT | §3.2、§4；窗口先验 | 点跟踪已有 FM 多假设；窗口内使用视频特征 | 已解决未知 ID 的出生消失与在线分配 |
| DiffuTrack | MDM、TPCL、关联与不确定性实验；公开代码 | 框分布＋在线关联是直接先例；外观对比与运动损失可区分 | 已严格验证该仓库下所有论文分数 |
| OA-SORT | §4、局限 | 观测偏移与状态更新是替代机制 | 所有遮挡误差都只需运动生成 |
| DOA-SORT | §3、§4.1–4.2、局限 | 混合观测分布与方向偏移先例 | DanceTrack val 结果等于 test 泛化 |
| MOTIP2 | §3.2–3.4 | 近邻身份扰动、距离加权 ID 监督 | 与本方案的生成器反传完全相同 |
| Constraint-Aware FM | §4–5，Eq.8 | 下游决策/约束对齐生成训练并非空白 | 已经完成 MOT 分配问题 |
| TrajE | 摘要、研讨会论文方法概述 | MDN 多假设 MOT 的直接早期先例 | 在当前 DanceTrack 协议下必然优于 FM |
| DMMTracker | 作者机构摘要 | 身份可区分的位置预测动机有先例 | 已逐条核实其全文训练机制 |
