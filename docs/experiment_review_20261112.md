## 2. 如何解读已有结果

### P1 有稳定的离线信号，但研究问题还没有被回答

三个固定 seed 的宏平均 normalized MSE 分别为 1.380908、1.385514、1.383229，零位移对照为 1.510670，平均降低 **8.44%**；每个 seed 在 8/8 视频上的 MSE 均更低。gap2–31 的样本加权 MSE 降低 **7.44%**，宏平均 IoU 从 0.843628 到 0.850501，增加 **0.006873**。宏平均与 gap 分组采用不同权重，不能混作同一总体指标。

这些结果支持继续尝试，也说明不必为了“更稳”立即增加 epoch、扩大编码器或重复训练。但三 seed 检验的是训练随机性，不能消除数据选择偏差，也不自动产生统计显著性。

目前最关键的四个缺口是：

1. **历史来自 GT 对齐的检测框。** 代码先生成样本再追加当前观测，时间上没有把当前检测送进历史；但 GT 帮助维护了身份对应。真实 tracker 的错配、错误出生、身份污染和缺失历史还未进入这个检验。
2. **现有比较没有击败 OC-SORT 的 KF。** 离线对照是最后观测不动与最后两次观测的恒速外推。恒速 MSE 很差并不说明所有传统运动模型都差；其 log-size 外推尤其需要保留逐维诊断，不能据此宣传优势。
3. **平均位置误差不等于实际关联。** 需要看正确检测能否过门控、竞争候选是否被排到后面、Hungarian 最终分配以及后续身份持续性。固定候选池中没有正确检测时，更准的预测也不能在该帧直接匹配到它。
4. **长间隔存在反向结果。** gap16–31 共 650 个样本，三个 seed 的 IoU 都低于零位移对照，平均差 **−0.008110**，尽管 MSE 更低。不能只报告 MSE；也不能直接将这个现象解释为多模态证据，损失权重、尺度预测和历史偏差都是竞争解释。

此外，75,428/80,458（93.75%）dev 样本为 gap1；8 段中有 4 段是此前已检查的困难 anchor。后续报告须保留 gap 分层和 anchor/其余视频分层，整个 motion-dev 都是开发集，后四段也不能包装为新的独立确认集。

### G2 支持“值得试运动预测”，没有证明“需要 FM”

D2 在 53 个失败事件中新增 22 个首轮正确匹配，但损伤 2/112 个成功对照；D3 新增 14/53，也损伤 7/112 个成功对照。两者说明位置因素值得干预，同时说明运动与检测定位、全局竞争不能简单分开归因。这些计数都是特定快照上的首轮分配，不是身份持续恢复率。

D5 同时把正确轨迹与正确检测置于相同 GT 框，构造出 IoU=1，在失败组新增 52/53 个正确匹配。这是分配一致性压力测试，不是可部署方法的收益上界，也不是“两个模块有协同效应”的证明。D1/D4 的窄范围零恢复同样不能证明历史污染或方向项在所有场景下无关。

因此保留创新台账 C1–C5 的未获支持状态。确定性方法有效也只证明可学习位置预测有价值；只有进一步超过确定性、Gaussian/MDN 并控制关联机制后，才可能支持 FM 的必要性。

## 3. 下一轮只回答一个问题

> 冻结当前 P1 checkpoint，在固定检测、自然 tracker 历史和原有生命周期下，只替换首轮关联所用的预测框，能否改善真实身份关联，同时不伤害原本成功的轨迹？

### A. 先补最小运行契约，不重新训练

- 复用三份固定 seed checkpoint、训练归一化和 8 段 motion-dev；本轮不增加模型参数、损失或新数据集。
- 为每个真实 tracker ID 维护过去实际匹配的检测历史。冻结哪些匹配阶段/分数可进入历史，核对与训练样本的检测筛选是否一致；不能用 GT 筛历史，也不能把 KF/ORU 插值状态冒充真实检测观测。当前帧关联结束后才能追加当前观测。
- 明确空历史、只有一次观测、gap>31、轨迹删除/重建的处理。建议不满足模型契约时回退原 KF 首轮预测并计数；NaN/Inf、非法宽高也必须有可见的错误计数和预定处理，不能静默吞掉。
- 仅向首轮关联传入替代框，不直接覆盖 KF 状态。方向项、门控阈值、第二轮和旧观测重匹配、生命周期保留原配置；最终不同的匹配自然会改变后续轨迹，这正是需要测的闭环效应。
- 保持左侧 padding、时间单位、图像尺寸和 state 解码一致。检查 tracker ID 与候选行顺序、删除后映射，以及模型开启后的输入确实不含 GT。B1-off 的旧等价结果不能代替这些针对性检查。

目前仓库只有窄接口和离线模型，不能把上述运行历史管理当成已经实现。先做一段固定片段的接口 smoke，只验时序/映射/数值，不用它选最优 checkpoint 或阈值。

### B. 最小闭环比较：6 个方法运行

| 变体 | 次数 | 目的 |
| --- | --- | --- |
| B0/KF，B1-off 等价入口 | 1 | 本轮同输入官方基线；若完整产物与协议完全匹配可复用，不必为了凑三次重复确定性输出 |
| 同接口零位移 | 1 | 排除只改变首轮预测接口或保守预测带来的收益 |
| 同接口恒速外推 | 1 | 可实现简单对照；数值异常按预先固定规则处理，不能看完结果才裁剪 |
| P1 原始配置 | 3 | 三个现有 seed 全部运行，无最佳 seed 选择、无重训 |

每个方法运行均覆盖全部 8 段；“6 个”指方法级运行，不是六次训练。原 P1 保留可用 gap1–31 的主比较。已知 gap16–31 风险可另登记“gap>=16 回退 KF”次要变体（三 seed，额外 3 次）；它只能作为开发性限制方案，不能替代或隐藏原配置结果。建议先完成主比较，若需该变体，在读取它的结果前另立协议并标明由既有负结果启发。

另可在记录下来的 **B0 固定历史快照** 上批量计算 P1 候选门控/排名，以区分即时分配效果和闭环反馈。这是同一轮的诊断输出，不增加一套训练，也不能替代自然闭环主结果。

### C. 在完整结果揭晓前固定评价与决策

主评价用官方 TrackEval 聚合 HOTA、AssA，支持指标 IDF1、DetA、IDSW 等；同时给逐视频配对差异和三个 seed 全部结果。单视频 HOTA 的均值不能冒充官方聚合值。

必须另外登记：

- gap1、2–3、4–7、8–15、16–31 分层，并保留当前正确检测不存在的情况；在线决策不读 GT，GT 仅供离线评价。
- 以 GT 可见性/检测可用性或固定 B0 规则构建共用事件集合，不能各方法按自己的失败另选分母。把“正确检测重新出现时接回原 ID”与“此后连续 N 个可评价帧维持身份”分开；运行前确定 N、边界删失和不可解析情况。
- 固定成功对照的损伤数与分母；对新方法触发的新增失败也单列。长 gap 样本可能很少，应报告数量和逐视频差异；证据不足时标记不确定，不能因均值没下降就宣布安全。
- tracker-only 延迟的 warm-up、同步、设备、批处理、p50/p95；检测缓存条件下不冒充端到端 FPS。增加 eligible 覆盖率、实际替换率和每类 fallback 数量。
- 主比较、最小有意义增益、允许退化、长 gap 安全条件、延迟上限、预算与查看次数。**这些数值尚未冻结，本复盘不凭离线误差臆造 HOTA 阈值。** 下一步协议必须填实后再启动完整评价；开发性门不宣称显著性保证。

## 4. 跑完之后如何分支

| 结果 | 后续行动 |
| --- | --- |
| P1 自然闭环改善，跨视频/seed 方向较一致，安全与成本达标 | 开始小型 Gaussian 对照，再视条件校准和闭环信号决定是否加 MDN；仍不直接铺开 FM 矩阵 |
| 离线误差改善，固定快照门控/排名无改善 | 优先检查尺度/中心损失与关联目标不一致；可提出一次受限的损失或直接匹配对照，另立开发协议 |
| 固定快照有改善，自然闭环无改善或变差 | 优先查真实历史分布、反馈污染、生命周期与第二轮抵消；必要时只用 motion-train 构建 tracker-history 训练输入，严禁用 dev 重训 |
| 仅长 gap 明显受损 | 明确限制适用 gap，并评估预登记回退变体；不得声称全 gap 改善 |
| 简单零位移/恒速与 P1 相当或更好 | 保留简单方案作为后续强对照，重新判断学习预测器的投入价值 |
| 完整闭环和一次有机制依据的有限修正均无信号 | 暂停增加模型复杂度，重新评估观测建模/关联决策方向；不靠堆 FM 或延长训练回避负结果 |

这里的“先过确定性闭环门”是当前投入排序，**不是确定性失败就从逻辑上否定概率模型**。若以后能给出单点预测受限、多候选排序确有额外信息的区分证据，可单独立小规模概率探针；现有材料尚不足以跳过这一步。

对毕业设计而言，已完成工作建立了可信的实验基础，但不能把基础设施、oracle 和离线误差直接算作方法创新。应尽快拿到第一个自然闭环正/负结论，再决定论文主线是否保留 FM。新的闭环证据出现前，环境重装、更多数据集、更多 GPU 利用率和更大的模型都不是当前瓶颈。
