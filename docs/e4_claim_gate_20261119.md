# E4 结果到主张的决策

**日期：** 2026-11-19<br>
**审阅：** 新鲜 Codex 代理，同系列 provisional；E4 完整性审计 `WARN`，数值门槛 `PASS`。本地未找到通用 `evidence_check.py`，因而没有独立的 claim 文件预检；原始摘要、审计与报告可逐项核查。

## 支持的窄主张

**`claim_supported=yes`，但仅针对条件化、GT 特权的构造性短程 headroom；总体信心中等。** 在 24 段 DanceTrack train-fit 的固定候选中，经 GT 确定历史 C 身份、当前正检测，再限定轨迹曾成熟且正常 CV+E 未被该检测更新的 454 个事件，单次强制该配对使五帧目标同 ID 正确输出净增 1,426 帧，全锚点净增 1,643 帧；9 个目标事件和 37 个有其他锚定身份的事件受损。五项预写门槛均通过。

这是局部特权反事实，**不是数学最优上界**。基线当帧目标正确输出为 0 与筛选条件有关；454 个窗口重叠，不能推断完整序列 HOTA/AssA/IDF1，也不能把每事件收益外推到全数据集。审计指出全部 oracle 轨迹没有逐帧归档，若逐项独立复算需要重跑；完整性 `WARN` 不因门槛通过而消失。

## 不支持的主张与下一步

E4 没有证明在线可观测量能识别正确配对，也没有产生可部署算法、留出集泛化或官方评测收益。E0–E3 的输出基线仍须保留；FM/MDN 和新的运动生成器尚无启动依据。

下一次只做**一个锁定的非 oracle 信息源测试**：优先用固定、无需训练的图像裁剪外观特征（例如归一化 HSV 颜色直方图）和当前/过去帧，选择一对一关联纠正；把干预次数与简单 IoU/关联 margin + 检测分数规则配平，比较 CV+E。先在 24 段 fit 确定唯一阈值或预算，再锁定到 8 段 train-heldout 一次评测。必须纳入所有在线可观察候选，报告已正确、失败与受损动作；E4 型 GT 失败只作诊断子集。若留出集的全锚点净收益和损伤不能超过最强简单规则，就停止此关联修复候选，不继续调外观阈值或训练 FM/MDN。这个计划尚未冻结或运行。
