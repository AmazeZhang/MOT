## 升级与降级规则

1. 计划中的实验不是 provenance；只有可复查的完整 run 才是。
2. C1–C5 任一主张准备升级时，先填写决策记录，列出最强负结果、方差和未解释异常。
3. 发现完全先例时，C0 立即降级为 `OVERSTATED` 或 `REJECTED`，C5 同步重新评估。
4. MDN 与 FM 相当、直接分类器更好、只有人工缺失改善或只有 oracle 改善，都必须保留并触发主张收缩。
